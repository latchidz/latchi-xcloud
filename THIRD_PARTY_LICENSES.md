## Microsoft Edge WebView2

يستضيف التطبيق صفحات Xbox Cloud Gaming عبر **WebView2 Runtime** (محرك Chromium من Microsoft، مثبّت مسبقاً مع ويندوز 10/11). لا يُعاد توزيع Runtime داخل التطبيق؛ يستخدم التطبيق النسخة المثبتة على جهاز المستخدم وفق شروط Microsoft. العلامات التجارية Microsoft وXbox ملك لأصحابها.

## إخلاء مسؤولية

LATCHI xCLOUD مشروع مستقل **غير تابع لـ Microsoft أو Xbox** ولا يدعم أي رعاية رسمية منهما. الخدمة نفسها (Xbox Cloud Gaming) تبقى خدمة Microsoft الأصلية، والتطبيق مجرد بيئة تشغيل مخصصة حولها. Better xCloud مشروع مستقل أيضاً بترخيص MIT لمؤلفه redphx.
