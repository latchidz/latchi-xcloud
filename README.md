## لماذا؟

فتح xbox.com في متصفح عادي على حاسوب ضعيف (4GB RAM، قرص HDD، رسوميات مدمجة) يعني: واجهة متصفح كاملة تستهلك الذاكرة، بلا تكامل Better xCloud إلا عبر إضافات يدوية، وتجربة أشبه بموقع منها بتطبيق. **LATCHI xCLOUD** يعطيك:

1. ثبّت وافتح — سجّل دخولك بحساب Microsoft (تسجيل الدخول يبقى بينك وبين Microsoft عبر صفحاتهم الرسمية داخل التطبيق).
2. Xbox Cloud Gaming يفتح مباشرة **وBetter xCloud مفعّل تلقائياً** — بلا Tampermonkey، بلا سكربتات يدوية.
3. التحكم بيد Xbox يعمل مباشرة، ملء الشاشة بF11، والعب.

## الميزات

### بيئة تشغيل مخصصة
- **محرك WebView2 (Chromium)** — نفس محرك Edge الرسمي الذي تدعمه الخدمة: WebRTC، WebGL، فك ترميز الفيديو بالعتاد، Gamepad API — كلها أصلية ومفعّلة
- واجهة داكنة كحلي/ذهبي هوية LATCHI، بلا أي واجهة متصفح (لا شريط عنوان، لا تبويبات، لا قوائم)
- ملف تعريف متصفح **مخصص ومعزول** للتطبيق — لا يقرأ ولا يلمس بيانات Chrome/Edge عندك، وجلسة تسجيل دخولك تبقى محفوظة بين الجلسات

### تكامل Better xCloud الرسمي
- النسخة المدمجة: **v6.7.12** من الإصدار الرسمي (redphx/better-xcloud) — ملف مطابق بايتاً ببايت، بلا أي تعديل
- حقن تلقائي عند document-start تماماً كما يتوقع السكربت، مع احترام قواعد @match/@exclude الخاصة به
- إعدادات Better xCloud نفسها تبقى داخل صفحة xCloud كما صممها مؤلفها — لا نستبدلها ولا نكسرها
- **نظام تحديث آمن**: فحص الإصدار الأحدث من المصدر الرسمي فقط → تنزيل → تحقق (اسم/إصدار/حجم/بصمة) → تجهيز → تفعيل عند إعادة التشغيل فقط (أبداً أثناء اللعب) → **استرجاع تلقائي للنسخة السابقة إذا فشلت الجديدة**

### أداء الجهاز الضعيف
- التطبيق المضيف خفيف جداً (WPF/.NET 8)؛ الصفحة تعمل بمحرك واحد ثابت طوال الجلسة
- **تسريع العتاد للفيديو يبقى مفعّلاً دائماً** — لا يُعطَّل أبداً (أساس بث الألعاب)
- وضع «الجهاز الضعيف» يبسّط واجهة التطبيق فقط، بلا مساس بالبث
- أثناء اللعب تصبح الواجهة شبه معدومة: لا مؤقتات، لا تحديثات خلفية، لا قياسات

### الأمان والخصوصية
- **بلا إنترنت إضافي**: التطبيق يتصل مباشرة بخدمات Microsoft/Xbox فقط — بلا VPN، بلا بروكسي، بلا خوادم وسيطة
- **بلا تتبع نهائياً**: لا تحليلات، لا قياسات، لا جمع بيانات — كل شيء محلي في جهازك
- التنقل محصور بقائمة بيضاء لنطاقات Microsoft/Xbox — أي موقع آخر يُحظر
- النوافذ المنبثقة غير المسموحة تُحظر، والتنزيلات تُلغى دائماً
- الصلاحيات مرفوضة افتراضياً (الميكروفون مسموح لxbox.com فقط — للدردشة الصوتية)
- لا يُنشئ التطبيق حقول كلمات سر ولا يلمس بيانات اعتمادك — تسجيل الدخول صفحات Microsoft الرسمية نفسها

## التحميل والتثبيت

من **Actions** في هذا المستودع (لا يوجد Release عام):

| الملف | الوصف |
|---|---|
| `LATCHI-xCLOUD-0.1.0-x64-Setup.exe` | مثبّت لكل مستخدم — **بلا صلاحيات مدير**، قائمة ابدأ + اختصار سطح مكتب اختياري |
| `LATCHI-xCLOUD-0.1.0-portable-win-x64.zip` | نسخة محمولة — فك الضغط وشغّل |
| `artifact-manifest.txt` | الأحجام وبصمات SHA-256 الحقيقية |

**المتطلبات:** Windows 10/11 (64-bit) + Microsoft Edge WebView2 Runtime (مثبّت افتراضياً مع ويندوز الحديث). المتصفح نفسه غير مطلوب.

## بنية البيانات

```
%LOCALAPPDATA%\LATCHI\xCLOUD\
├── BrowserProfile\   ← ملف تعريف WebView2 المخصص (الجلسة + إعدادات BxC)
├── BetterXCloud\     ← السكربت النشط + السابق (للاسترجاع) + منصة التحديثات
├── Settings\         ← إعدادات التطبيق
├── Logs\             ← سجلات محلية (بلا أي بيانات حساسة)
└── Updates\          ← تحديثات مجهزة + قائمة النسخ الفاشلة
```

إزالة التطبيق **لا تحذف بياناتك** (الجلسة والإعدادات تبقى).

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| شاشة «تعذّر التحميل» | راجع اتصال الإنترنت ثم «إعادة المحاولة»، أو افتح التشخيصات (زر النبض في الشريط) |
| «Better xCloud تعذّر التشغيل» | غالباً تحديث فاشل — سيُسترجع السابق تلقائياً عند إعادة التحميل؛ أو من الإعدادات → استرجاع النسخة السابقة |
| يد التحكم لا تعمل | صلها ثم افتح التشخيصات للتأكد من اكتشافها (Gamepad) |
| صفحة تسجيل الدخول بطيئة | عادي على أول مرة؛ الجلسة تُحفظ فلا تعيدها في كل مرة |

## البناء من المصدر

```bash
git clone https://github.com/latchidz/latchi-xcloud
cd latchi-xcloud
dotnet build -c Release                     # تجميع
dotnet test  -c Release                     # 55 اختباراً للنواة
dotnet run --project src/LatchiXcloud.App -- --smoke   # فحص ذاتي شامل على الويندوز
```

الإنتاج الرسمي (Setup + Portable) يُبنى حصراً على **GitHub Actions** — نفس الـworkflow يفحص الـexe الإنتاجي نفسه بفحص smoke حقيقي (WebView2 حقيقي + حقن السكربت + حجب التنقل + جسر الرسائل) قبل التغليف.

## البنية

```
src/LatchiXcloud.Core     ← نواة قابلة للاختبار: إعدادات، سياسة تنقل، محلل ميتاداتا السكربت، نظام تحديث مع rollback
src/LatchiXcloud.App      ← واجهة WPF + WebView2: شريط مخصص، جسر، تراكبات، إعدادات، تشخيصات، فحص ذاتي
resources/                ← سكربت Better xCloud الرسمي (v6.7.12) + manifest الإسناد
tests/                    ← 55 اختبار xUnit
installer/                ← سكربت Inno Setup (بلا صلاحيات مدير)
.github/workflows/build.yml ← البناء والفحص والتغليف على GitHub Actions
```
